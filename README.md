# memory-game

Игра «Найди пару» на тему космоса: 16 карточек (8 пар), нужно найти все пары за как можно меньшее число ходов.

**Демо:** https://mamedovshuxrat.github.io/memory-game/

## Как играть

- Кликните по карточке, чтобы перевернуть её, затем по второй.
- Если картинки совпали, пара остаётся открытой.
- Если нет, карточки закроются через долю секунды (пока они закрываются, кликать нельзя).
- Игра заканчивается, когда найдены все 8 пар. Появится окно с числом ходов.
- Кнопка «Новая игра» сразу сбрасывает партию и заново перемешивает карточки.
- Кнопка «Таблица лидеров» показывает 10 лучших результатов (меньше ходов — выше место). Результаты хранятся в `localStorage` браузера.
- Окна закрываются кнопкой, кликом по затемнённому фону или клавишей Escape.

## Запуск

Проект использует ES-модули, поэтому его нельзя открыть двойным кликом по `index.html` (`file://`). Нужен локальный сервер, например расширение VS Code **Live Server**:

1. Склонируйте репозиторий.
2. Откройте папку в VS Code.
3. Нажмите «Go Live» (это расширение в VS Code) в статус-баре.  

## Технологии

- HTML, SCSS (методология БЭМ), JavaScript (ES-модули, без библиотек)
- Вся разметка создаётся через `document.createElement` (в `index.html` в `<body>` только `<script>`)

## Стили

Стили написаны на SCSS:

- `styles/style.scss` — основной файл (сброс, шрифты, общие классы);
- `styles/base/` — переменные, сброс, шрифты;
- `styles/blocks/` — стили блоков (`_card.scss`, `_modal.scss` и т.д.).

Компиляция: расширение VS Code **Live Sass Compiler** («Watch Sass» в статус-баре).
Результат `styles/style.css` подключён в HTML и хранится в репозитории,
потому что GitHub Pages не компилирует SCSS.

## Структура проекта

```
assets/        карточки (svg), шрифты, данные карточек
js/components/ компоненты интерфейса (header, board, card, modal ...)
js/utils/      игровая логика и вспомогательные функции
styles/        SCSS и скомпилированный CSS
```
